An Individual Taxpayer Identification Number, or ITIN, is a federal tax-processing number for a person who is not eligible for a Social Security number but needs to be identified for a U.S. tax purpose. Americans abroad most often encounter Form W-7 when a foreign spouse, dependent, estate beneficiary, or other non-eligible person must be identified on a U.S. return.

The application is not a substitute for deciding whether a return must be filed. First classify the taxpayer, filing status, income, election, and tax year. Then determine whether an ITIN is actually required and which exception, if any, supports the application. The IRS instructions for [Form W-7](https://www.irs.gov/instructions/iw7) control the current process.

## Start with the tax purpose

An ITIN application should be tied to a specific federal tax purpose. A request made only to obtain a general identification number may not be enough. Common tax purposes include filing a joint return after a qualifying election for a nonresident alien spouse, claiming a dependent who is not eligible for a Social Security number, reporting an item that requires the person’s identification, or responding to an IRS instruction that specifically calls for an ITIN.

Write the purpose in plain language before gathering documents. Identify the tax year, the return type, the applicant’s relationship to the taxpayer, and the line or schedule where the applicant will appear. If the purpose is a foreign-spouse filing decision, compare married filing jointly, married filing separately, and any applicable election before ordering translations or submitting a package. The [foreign-spouse guide](/guides/married-to-foreign-spouse) explains why an identification request should be part of a broader household analysis.

## Who may need an ITIN while abroad?

The most familiar applicant is a nonresident alien spouse who will be identified on a joint federal return after the couple makes the applicable election. Other cases include a dependent who has no Social Security number and is eligible to be claimed under the current rules, a person receiving income that must be reported under their identifying number, or an applicant named in a return-related exception.

Do not assume that a spouse needs an ITIN simply because the spouse lives abroad or has no U.S. immigration status. The filing status and election drive the requirement. Likewise, do not assume that an ITIN creates immigration status, work authorization, or eligibility for federal benefits. It is a tax-processing number and should be handled as part of the tax file.

An applicant who is eligible for a Social Security number should generally pursue the Social Security process instead. The current W-7 instructions explain the relationship between an SSN application and an ITIN application. Filing both applications for the same tax purpose can create delays or an inconsistent record.

## Build the application packet before mailing anything

An overseas packet normally has three parts: the signed federal return or documented exception, the completed Form W-7, and evidence of identity and foreign status. The evidence must satisfy the current IRS requirements. A passport is commonly used because it can establish identity and foreign status in one document, but the current instructions determine whether the copy, certification, or alternative documents are acceptable.

Create a document index with the applicant’s full legal name, date of birth, country of citizenship, current foreign address, and the exact tax purpose. Confirm that the spelling is consistent across the passport, marriage certificate, return, and Form W-7. If names differ because of marriage, transliteration, or local naming conventions, explain the difference rather than hoping the reviewer will infer it.

Check every date and address. A return may show a mailing address that differs from the applicant’s residence. That can be legitimate, but the file should state why. If a document is not in English, use the translation method required by the current instructions and keep the original record with the translation. Do not send irreplaceable originals unless the IRS specifically requires them and you have considered the recovery risk.

## Applying from outside the United States

The IRS lists multiple submission routes, including direct mail and assistance through an Acceptance Agent or Certifying Acceptance Agent where available. The permitted route depends on the applicant, the documents, and the current program rules. Start with the [IRS ITIN overview](https://www.irs.gov/individuals/individual-taxpayer-identification-number) and the current W-7 instructions rather than an old blog post or a courier’s generic checklist.

If mailing from abroad, use a trackable service and retain a complete copy of the packet. Record the date sent, delivery confirmation, return address, and every document included. A foreign courier may require customs information even though the envelope contains tax paperwork rather than merchandise. Do not write a Social Security number, bank password, or other unnecessary sensitive information on the outside of the package.

An Acceptance Agent may be useful when the identity documents are difficult to certify, the applicant is outside the United States, or the return has several connected issues. Verify the agent’s current status and ask what the agent will review, retain, certify, and return. The agent does not decide a complex filing-status or treaty question for the family. Those questions should be resolved before the application is assembled.

## The return and the ITIN application must agree

If the application is attached to a return, reconcile the return to the W-7 before submission. Check the applicant’s name, date of birth, country, relationship, filing status, election statement, dependents, income, withholding, and requested credits. A W-7 that says one thing while the return treats the person differently can produce a notice or rejection even if the identity documents are valid.

For a foreign spouse, model the full household inventory. Include the spouse’s worldwide income, local tax paid, foreign accounts, pensions, investment funds, business interests, and any community-property issues that could affect a separate-return analysis. The [expat tax guide](/guides/expat-tax-guide) and [expat tax filing service](/services/expat-tax-filing) can help organize that review. An ITIN does not make the filing-status decision for you.

## Common application problems

The most common problem is an unsupported tax purpose. The second is incomplete identity evidence: an expired document, an uncertified copy, inconsistent names, missing pages, or a document that proves identity but not the required foreign status. The third is a mismatch between the return and the W-7, such as an incorrect relationship, a missing election statement, or a taxpayer identification number entered in the wrong field.

Other problems arise from using a form version that is no longer current, omitting a signature, using an outdated address, or mailing only the W-7 without the required return or exception evidence. Keep a version-controlled copy of the form and the instructions used. Note the date accessed and the tax year. Tax forms change, and a packet assembled from several years of online instructions is difficult to defend.

Do not send an incomplete package merely to start the clock. If one document is missing, create a short gap list and resolve it. If the applicant’s legal name or status is genuinely uncertain, pause and obtain the civil record or specialist advice. A fast submission that creates a rejection and a second identity review may take longer than a complete first packet.

## After submission

Keep the delivery record and watch for IRS correspondence. If the IRS requests additional information, compare the request with the original packet and answer the specific gap. Do not mail a new, unrelated packet without explaining whether it supplements or replaces the first application. If the applicant receives an ITIN, save the notice with the tax return and confirm how the number will be used in future filings.

An ITIN can expire under the rules described by the IRS if it is not used or renewed when required. Before filing a later return, check the current status rather than copying an old number into the new return. Also update the family’s address, name, filing status, and identification records if circumstances changed.

## A document checklist for an overseas applicant

Before submitting, make a checklist that separates identity evidence from tax-purpose evidence. Identity evidence answers who the applicant is. Tax-purpose evidence answers why the applicant is being identified on the U.S. return. The two questions are related but not interchangeable. A clear passport copy may establish identity while the return, election statement, or exception document establishes the tax purpose.

For the identity side, record the document title, issuing country, document number in a secure internal file, issue date, expiration date, and whether the copy is certified in the manner required by the current instructions. For the tax-purpose side, record the return year, filing status, relationship, source of income or credit, and any exception number used. This index helps prevent a reviewer from searching through a package without context.

Check the spouse or dependent’s name against the civil record and the return. A marriage certificate can show a surname change, but it may not explain a different transliteration used on a passport. Add a short note and supporting record. If the applicant uses multiple names in local documents, do not choose one casually; determine which name the tax form and identity evidence should use under the current instructions.

Keep a redacted working copy for preliminary review and a secured final copy for submission. The redacted copy can omit the full document number and unrelated personal data. The final copy should be complete enough for the authorized preparer or agent to verify the application. Do not store identity documents in a shared folder without access controls and a retention plan.

## A timing plan when the return deadline is close

If the return deadline is approaching, identify whether the taxpayer can file an extension, whether the ITIN is necessary to file, and whether the return can be prepared accurately while the number is pending. The correct sequence depends on the filing status, credits, and current IRS instructions. Do not solve a timing problem by filing an unsupported return or omitting a spouse who must be identified.

Create three dates: the tax return due date, the latest safe mailing date for the W-7 packet, and the date on which the taxpayer must follow up. A foreign mailing time is not the same as IRS processing time. Preserve the extension confirmation, courier receipt, and a copy of the packet. If a return is sent with the application, save the exact signed version that was mailed.

If the application is rejected, read the rejection reason before resubmitting. Correct the exact missing item, update the form if a new version is required, and explain any change in the tax purpose or applicant information. A second packet should be linked to the first by reference, not treated as a completely new story. If the rejection reveals a filing-status or eligibility problem, stop and reassess the underlying return.

## Keep the ITIN decision connected to later years

The number is one part of a continuing record. Store the assignment notice with the return, the spouse or dependent profile, and the filing-status workpaper. In the next year, confirm the number is entered correctly and that the person’s name, address, relationship, and tax purpose have not changed. If the spouse obtained an SSN, check how the current return instructions address the transition rather than continuing to use the ITIN without review.

Also record whether the family made an election that continues or can be revoked, whether the spouse’s income changed, and whether new foreign accounts or investments appeared. The ITIN does not answer those questions, but forgetting them can make a later return inconsistent with the first one. A year-to-year checklist reduces the chance that a preparer copies last year’s assumptions.

The cleanest process is to treat Form W-7 as a controlled filing component: one source of truth for identity, one source of truth for the tax purpose, one index of evidence, and one signed final package.
